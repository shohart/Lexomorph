# 🔒 Безопасность

**[Read this in English](SECURITY.md)** (основной вариант; этот файл — его русская адаптация).

## Как сообщить об уязвимости

О предполагаемой уязвимости сообщайте приватно, через страницу GitHub
**Security > Report a vulnerability** этого репозитория. Не включайте в
публичный issue личный текст диктовок, аудио, учётные данные и полные
диагностические логи.

## Как защищён Lexomorph

**Сеть.** Речь распознаётся на вашем устройстве, звук никуда не отправляется.
Приложение обращается к сети только для загрузки моделей (закреплённые версии,
SHA-256 проверяется), проверки обновлений и того, что вы включаете сами:
собственный адрес LLM (он получает диктуемый текст и инструкцию, не звук) и
синхронизация аккаунта (правила замен, ASR-термины, свои режимы и счётчики
использования). Аналитики и телеметрии в коде нет. Полная таблица — в
[PRIVACY.md](PRIVACY.md) (на английском).

- **Проверка обновлений.** На macOS она выполняется при открытии панели, плюс
  фоновая проверка, которая **по умолчанию выключена**. На Windows автоматическая
  проверка **по умолчанию включена** и отключается в «Настройки →
  Дополнительно». В обоих случаях запрашивается только список релизов GitHub;
  приложение Windows открывает страницу релиза и ничего не скачивает и не
  запускает само.
- **Аккаунты.** Для работы приложения аккаунт не нужен. Он есть только у
  необязательной синхронизации, которая выключена, пока вы не войдёте. Как
  сервер синхронизации (его ведёт владелец проекта) хранит учётные данные и
  данные на диске, здесь не документировано и не проверялось.

**Хранение секретов.**

- **Ключ API** собственного адреса LLM хранится **открытым текстом**: в
  настройках (UserDefaults на macOS) или в `Settings.json` (Windows). Считайте,
  что каждый, кто может прочитать ваш профиль, прочитает и ключ; используйте
  ключ, который можно отозвать.
- **Токен синхронизации** хранится в Keychain macOS (service
  `com.local.lexomorph.vocab-sync`), а на Windows — зашифрованным через DPAPI
  для текущего пользователя в `VocabularySync.token`. Пароль не хранится.
- История и `DictationTrace.jsonl` содержат диктуемый текст и не шифруются; они
  остаются на вашем компьютере.

**Релизные сборки macOS** подписаны сертификатом разработчика («PolterType
Dev») и **не нотаризованы Apple**. Поэтому ZIP, скачанный через браузер, может
вызвать предупреждение Gatekeeper. Установщик по умолчанию скачивает релиз с
закреплённой версией и проверяет его SHA-256, версию, bundle identifier,
архитектуру, подпись кода и нужные права на микрофон. Gatekeeper он через
`xattr` не отключает. Локальные сборки через `scripts/build-app.sh` подписываются
ad-hoc, если не передать `SIGN_IDENTITY`; `scripts/install-local.sh` использует
локальный сертификат Apple Development, когда он есть. Если нужен бинарник,
собранный у себя, запустите установщик со сборкой из исходников, описанный в
[README.ru.md](README.ru.md).

**Установщик Windows** (`Lexomorph-Setup-X.Y.Z.exe`) **не подписан
Authenticode**, поэтому SmartScreen может предупредить о неизвестном
издателе. Скачивайте его только со страницы Releases этого репозитория. Он
ставится для текущего пользователя и не требует прав администратора.
