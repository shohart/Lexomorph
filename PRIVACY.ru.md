# 🔒 Конфиденциальность

**[Read this in English](PRIVACY.md)** (основной вариант; этот файл — его русская адаптация).

Lexomorph (ранее SuperDictate Next) построен вокруг локального распознавания речи.
Здесь перечислено, что остаётся на вашем устройстве, а что может его покинуть.
Адрес сервера синхронизации и репозиторий пока сохраняют старое имя намеренно, см.
[docs/branding/MIGRATION_NOTES.md](docs/branding/MIGRATION_NOTES.md).

## 💾 Данные, остающиеся на устройстве

- **Звук распознаётся локально.** Звук с микрофона никогда не отправляется в сервис
  транскрибации. Распознавание идёт во вспомогательном процессе на вашем CPU (в Windows
  с поддерживаемым Intel NPU можно по желанию использовать NPU).
- **Расшифровки хранятся локально в читаемом виде.** История диктовок и настройки лежат
  в `~/Library/Application Support/Lexomorph` (macOS) или `%LOCALAPPDATA%\Lexomorph`
  (Windows). История содержит надиктованный текст.
- **`DictationTrace.jsonl`.** Начиная с 0.9.7 локальный файл записывает для последних
  2000–4000 диктовок, что написало распознавание, текст после правил и итоговый текст.
  Он остаётся на вашем компьютере. Удалите его, если он вам не нужен.
- **Словарь замен и термины ASR** хранятся локально (`corrections.sqlite` на macOS).
- **Диагностические логи** лежат в `~/Library/Logs/Lexomorph-*` (macOS). Нет гарантии,
  что в них нет текста расшифровок; не публикуйте логи, не прочитав их.
- **Прерванные записи.** Если приложение аварийно завершилось, незаконченный звук
  сохраняется для восстановления и удаляется после обработки.
- **API-ключи хранятся открытым текстом.** Если вы настроили собственный endpoint LLM,
  его API-ключ записывается в настройки без шифрования (macOS UserDefaults, Windows
  `Settings.json`). Не используйте ключ, который нельзя отозвать. Токен синхронизации
  хранится в связке ключей macOS или защищён Windows DPAPI.
- В приложении нет кода аналитики или телеметрии.

## 🌐 Что может покинуть устройство

| Что | Куда | Когда | Что отправляется |
|---|---|---|---|
| Модели речи и пунктуации | huggingface.co (закреплённые ревизии, проверка SHA-256) | при первом запуске или при выборе другой модели | запрос файла |
| Файл Silero VAD | huggingface.co | автоматически после загрузки модели речи | запрос файла |
| Локальные модели LLM и адаптер коррекции | закреплённый каталог моделей; адаптер из GitHub-репозитория проекта | когда вы нажимаете «скачать» | запрос файла |
| Проверка обновлений | api.github.com, raw.githubusercontent.com | macOS: при открытии панели, а также фоновая проверка, если вы её включили (по умолчанию выключена). Windows: автоматически по умолчанию | запрос списка релизов |
| Установщик | github.com, raw.githubusercontent.com | при запуске `install.sh` | скачивает релиз и проверяет его |
| Коррекция или рерайт через LLM на вашем endpoint | введённый вами URL | только если выбран собственный endpoint (по умолчанию выключен) | **надиктованный текст и инструкция** (без звука), с вашим API-ключом |
| Синхронизация аккаунта | сервер владельца проекта `superdictate.bykovlegal.ru` (код в `server/vocab-sync`) | только после входа в аккаунт (по умолчанию выключена) | правила замен (исходный текст, замена, происхождение, флаг подсказки ASR) и термины ASR; с 1.0.0 (не выпущена) также названия, цвета и инструкции ваших режимов и посуточные счётчики использования; e-mail и пароль для входа |

Всё, что вы диктуете и отправляете на собственный endpoint, обрабатывается по условиям
этого провайдера, а не по этой странице. Содержимое синхронизации хранится на сервере
синхронизации; как этот сервер хранит учётные данные и данные в покое, здесь не
документировалось и не проверялось.

Синхронизация словаря замен между Mac через папку записывает один JSON-файл в
выбранную вами папку; всё, что синхронизирует эту папку (iCloud, Dropbox, Syncthing),
его видит.

## 🔐 Разрешения macOS

- **Микрофон** записывает речь, пока диктовка активна.
- **Универсальный доступ** вставляет полученный текст в поле ввода в фокусе.
- **Мониторинг ввода** отслеживает настроенную глобальную горячую клавишу.

В настройках конфиденциальности macOS приложение отображается как **Lexomorph**.
Поскольку в 1.0.0 изменился идентификатор пакета, macOS считает его новым приложением
и запрашивает эти разрешения заново.
