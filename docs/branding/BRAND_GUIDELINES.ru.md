Язык продукта и маркетинга — английский. Английский же — основной язык всей документации; русские файлы (`*.ru.md`)

называется SuperDictate (репозиторий, домен сервера синхронизации, Python-пакет, имена в C++) и почему — написано в
`MIGRATION_NOTES.md`.

## 2. Тон и редакционные правила

Точный, спокойный, технологичный. Простой английский без рекламных преувеличений. Польза описывается проверяемыми
сценариями.

Недоказанные абсолюты запрещены: «100% privacy», «100% local», «zero hallucinations», «flawless transcription»,
«learns instantly», «works entirely offline» (первая загрузка моделей требует сети), «no account» без оговорки про
необязательную синхронизацию, «logs avoid transcript text» (есть `DictationTrace.jsonl`).

Хорошо: «Keep preferred terminology consistent across dictations.», «Review and manage what the app remembers.»,
«Choose local models or a remote endpoint of your own.»
Плохо: «The AI reads your mind.», «Never makes mistakes.», «Learns your style automatically.» (обучение по правкам
охватывает только короткие правки слов и фраз, работает по эвристикам и с отменой).

Правило для персонализации: описывать реализованный механизм (словарь замен, обучение по правкам, подсказки
распознаванию, режимы рерайта). Дообучения на данных пользователя нет, так писать нельзя. Фраза «ничего не обучается
на вашем устройстве и на ваших данных» верна; фраза «в продукте нет дообученных моделей» неверна (коррекция использует
адаптер LoRA, который проект обучил заранее).

Не называть продукт «диктофоном», «сервисом ИИ-магии» или «голосовыми заметками». Использовать: adaptive dictation,
personal language adaptation, context-aware rewriting (только для режимов рерайта; контекст приложения не
используется), local-first writing workflow, correction-driven personalization.

Функции, которых нет (подстройка под голос, адаптивная маршрутизация, Lexomorph Studio, Lexomorph SDK, мобильные
клиенты, синхронизация настроек), не заявляются. Невыпущенное помечается «unreleased» или «planned».

## 3. Названия областей

Утверждено только название **Lexomorph**. «Lexomorph Core», «Lexicon», «Rules», «Sync» из спецификации — предложения;
пока владелец их не утвердил, в README они не используются как названия функций. Пустые пакеты ради названий не
создавать. Studio и SDK — только на будущее.

## 4. Визуальная система

Стиль: спокойный технологичный минимализм. Тёмные глубокие поверхности, точная типографика, один графический сюжет
(сигнал превращается в упорядоченные строки текста), лёгкая сетка, сдержанное свечение.

Избегать: клишированных микрофонов, мозгов из линий, цветных 3D-шаров, перегруженного неона, пустых графиков
волны, выдуманных скриншотов интерфейса, выдаваемых за настоящие.

### Типографика

Рекомендуется Inter для интерфейса и документации; Sora SemiBold или Inter SemiBold для крупных материалов; запасные —
IBM Plex Sans или Manrope. Файлы шрифтов в репозиторий и релизные пакеты не добавлять, пока не проверена лицензия на
распространение. В SVG (когда они появятся) использовать системный запасной шрифт.

### Знак

Идея: «morphing L». Волнистый штрих переходит в строгую ортогональную букву L. Финальная иконка в поставке —
квадратный монограммный знак «LM». Требования: квадрат, безопасные поля не меньше 12%, никакой мелкой микротипографики,
читаемость на 24–32 px и проверка на 16 px, работа в одном цвете и на светлой и тёмной темах. Системные скругления для
macOS и Windows накладывает сама платформа; в базовый мастер их закладывать не нужно.

Иконка приложения (`icon/Lexomorph.icns`, `windows/assets/Lexomorph.ico`) и шаблонный глиф строки меню macOS
(`swift/Resources/lexomorph-menubar*.png`) встроены в обе сборки. Остаточные вопросы, которые не перепроверялись в
настоящем Dock и трее, перечислены в `MANUAL_OWNER_ACTIONS.ru.md`.

### Карточки функций

Все шесть карточек пересозданы в ветке `feat/brand-cards` с текстом, сверенным с кодом, и показаны в галерее README:
Adaptive Dictation, Personal Vocabulary, Correction Learning, Style Modes, Cross-Device Sync, Local-First Privacy.
Правила для текста карточек (карточку, которая их нарушает, публиковать нельзя):

- Никакой подстройки под голос пользователя: единственная «адаптация» распознавания — подсказки терминов из словаря.
- Никакой синхронизации «настроек»: синхронизируются словарь замен, ASR-термины, свои режимы письма (имя, цвет,
  инструкция) и счётчики использования по дням — через аккаунт, в который пользователь вошёл сам. Ни телефона, ни
  мобильного клиента нет.
- Никакого безоговорочного «your data stays with you»: звук всегда остаётся на устройстве, но текст уходит на
  собственный LLM-адрес, если пользователь его выбрал, и на сервер синхронизации, если пользователь вошёл.
- Обучение по правкам эвристическое, только для коротких правок, с отменой и возможностью отключить. Режимы письма
  требуют LLM (локальной или вашего адреса) и по умолчанию выключены.

В шапке три плашки: Local-first, Adaptive ASR, Style-aware rewriting. «Adaptive ASR» заметно сильнее реального
(подсказки терминов декодеру); текст на картинке нельзя править без исходника. Это записано в
`MANUAL_OWNER_ACTIONS.ru.md`.

## 6. Правила использования

- Пропорции не искажать. Для README на всю ширину брать PNG 1280 x 640.
- Social preview для GitHub: 1280 x 640 (рекомендация GitHub — 1280 x 640, минимум 640 x 320); проверить обрезку.
- Не публиковать в README и на картинках личные словари, диктовки, логи и ключи.
- Настоящий скриншот приложения — без личных данных; пока его нет, в README стоит помеченная заглушка.
- Лицензия, NOTICE и кредиты (Parakey, Richard Courtman; SuperDictate, shlgd) сохраняются. Переименование не отменяет
  авторство.
- Название `Lexomorph` на занятость (домены, товарные знаки, GitHub, brew, PyPI) не проверялось; спецификация не
  подтверждает юридическую чистоту.
- Фраза «formerly SuperDictate Next» используется один–два релиза или пока не опубликованы заметки о миграции.
