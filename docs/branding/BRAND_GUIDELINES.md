# Lexomorph: руководство по бренду

Выжимка из `BRAND_SPEC_RU.md` (поставка бренда, версия 1.0 от 10 ноября 2026) с поправками на то, что реально есть в
репозитории. Если этот файл и маркетинговый текст расходятся с кодом, прав код: см. `REBRAND_AUDIT.md`.

## 1. Идентичность

| | |
|---|---|
| Название | **Lexomorph** (lexicon + morph) |
| Прежнее имя | SuperDictate Next (до этого SuperDictate-Intel). В тексте для пользователей: «Lexomorph (formerly SuperDictate Next)» |
| Основной слоган | **Speak freely. Write precisely.** |
| Второй слоган | Your speech. Your words. Your style. |
| Описание в одну строку | A personal adaptive writing engine that turns speech into text shaped by your vocabulary, corrections and preferred writing style. |
| GitHub About | Personal adaptive writing engine: dictation, correction, and style-aware text transformation. |
| Сообщение о переходе | Lexomorph (formerly SuperDictate Next). Same project, a broader vision: from speech recognition to adaptive, personal writing. |

Язык продукта и маркетинга: английский. Это не ограничивает языки распознавания и интерфейса (в приложении есть RU/EN).

Что остаётся под старым именем (бандл, пути, идентификаторы, имена релизных файлов), описано в `MIGRATION_NOTES.md`.
Бренд меняет только то, что видит пользователь.

## 2. Тон и редакционные правила

Точный, спокойный, технологичный. Простой английский без рекламных преувеличений. Выгода описывается проверяемыми
сценариями.

Запрещены недоказанные абсолюты: «100% privacy», «100% local», «zero hallucinations», «flawless transcription»,
«learns instantly», «works entirely offline» (первая загрузка моделей требует сети), «no account» без оговорки про
необязательную синхронизацию, «logs avoid transcript text» (есть `DictationTrace.jsonl`).

Хорошо: «Keep preferred terminology consistent across dictations.», «Review and manage what the app remembers.»,
«Choose local models or a remote endpoint of your own.»
Плохо: «The AI reads your mind.», «Never makes mistakes.», «Learns your style automatically.» (обучение по правкам
идёт только по коротким правкам слов и фраз, эвристиками, с отменой).

Правило для персонализации: описывать реализованный механизм (словарь замен, автообучение по правкам, подсказки ASR,
режимы рерайта). Дообучения весов на данных пользователя нет, и так писать нельзя. Фраза «ничего не обучается на вашем
устройстве и на ваших данных» верна; фраза «в продукте нет дообученных моделей» неверна (коррекция использует
дообученный адаптер LoRA, обученный проектом заранее).

Не называть продукт «диктофоном», «сервисом AI-магии», «голосовыми заметками». Использовать: adaptive dictation,
personal language adaptation, context-aware rewriting (только для режимов рерайта; контекст приложения не
используется), local-first writing workflow, correction-driven personalization.

Функции, которых нет (адаптация под голос, адаптивный роутинг, Lexomorph Studio, Lexomorph SDK, мобильные клиенты,
синхронизация настроек), не заявлять. Невыпущенное помечать «unreleased» или «planned».

## 3. Названия областей

Утверждено только название **Lexomorph**. «Lexomorph Core», «Lexicon», «Rules», «Sync» из спецификации помечены как
предложения; пока они не согласованы владельцем, в README не используются как названия функций. Не создавать пустых
пакетов ради названий. Studio и SDK только на будущее.

## 4. Визуальная система

Стиль: calm technical minimalism. Тёмные глубокие поверхности, точная типографика, один графический сюжет
(сигнал превращается в упорядоченные строки текста), лёгкая сетка, ограниченное свечение.

Избегать: микрофонов-клише, мозгов из линий, цветных 3D-шаров, перегруженного неона, пустых waveform-графиков,
фиктивных скриншотов интерфейса, выдаваемых за настоящие.

### Типографика

Рекомендация: Inter для интерфейса и документации; Sora SemiBold или Inter SemiBold для крупных материалов; запасные
IBM Plex Sans или Manrope. Файлы шрифтов в репозиторий и релизные пакеты не вносить без проверки лицензии на
распространение. В SVG, когда они появятся, использовать системный fallback.

### Знак

Концепция: «morphing L». Волновой штрих переходит в строгую ортогональную букву L. Финальная иконка в поставке:
квадратный монограмма-знак «LM». Требования: квадрат, безопасные поля не меньше 12%, без мелкой микротипографики,
читаемость на 24–32 px и проверка на 16 px, работа в одном цвете и на светлой и тёмной теме. Системные скругления
для macOS и Windows наносит платформа; в базовый мастер их встраивать не следует.

Известные замечания к текущей иконке (решение за дизайнером и владельцем, см. `MANUAL_OWNER_ACTIONS.md`):
- закруглённый квадрат занимает примерно 97% холста (bbox 17..1007 x 31..1004 из 1024); шаблон Apple для macOS
  предполагает корпус около 824/1024 с полями, поэтому в Dock значок будет выглядеть крупнее соседних;
- монохромного глифа для строки меню macOS нет (приложение использует template-изображение и красит его по состоянию);
- читаемость на 16 px и вместе с цветной точкой состояния в трее Windows не проверялась.

**SVG-мастеров нет.** Вся графика растровая и сгенерирована. Файлов `assets/svg/*` и `assets/png/*`, на которые
ссылаются `ASSET_GUIDE.md` и `IMPLEMENTATION_TASK_EN.md`, в поставке нет; размеры карточек 458–471 px, а не 1200 x 675.
Поэтому не выполнен пункт 12 спецификации (SVG и PNG в репозитории): PNG есть, SVG нет. Нет и отдельных файлов
`app_icon_light`, `mark_transparent`, `wordmark_darkbg`, `mode_*`, `pipeline_diagram`, `release_card_template`,
`contact_sheet`. Диаграмма конвейера в README нарисована текстом по коду, а не взята из бренда.

Если понадобятся редактируемые исходники, их нужно заказать или нарисовать отдельно; растр нельзя честно называть
«мастером».

### Какие карточки можно показывать

| Карточка | В README | Причина |
|---|---|---|
| Personal Vocabulary | да, с подписью | словарь замен и подсказки ASR существуют; «used correctly» это не гарантия |
| Correction Learning | да, с подписью | автообучение существует, включено по умолчанию, эвристическое, только короткие правки, есть отмена |
| Style Modes | да, с подписью | режимы рерайта существуют, но выключены по умолчанию и требуют LLM; в приложении они называются Polish, Structured task, Official и свои |
| Adaptive Dictation | нет | подразумевает подстройку распознавания под пользователя; её нет, есть только подсказки терминов |
| Local-First Privacy | нет | «Your data stays with you» без оговорок; при выборе внешнего endpoint или включении синхронизации текст уходит с устройства |
| Cross-Device Sync | нет | обещает словарь, настройки и стиль на всех устройствах и рисует телефон; настройки не синхронизируются, мобильного клиента нет, режимы и статистика ещё не выпущены |

Шапка README содержит три плашки: Local-first, Adaptive ASR, Style-aware rewriting. «Adaptive ASR» заметно сильнее
того, что есть (подсказки терминов декодеру); текст на картинке не редактируется без исходника. Это зафиксировано
в `MANUAL_OWNER_ACTIONS.md`.

## 6. Правила использования

- Пропорции не искажать. Для README шириной 100% использовать PNG 1280 x 640.
- Social preview для GitHub: 1280 x 640 (рекомендация GitHub 1280 x 640, минимум 640 x 320); проверить обрезку.
- Не публиковать в README и на картинках приватные словари, диктовки, логи, ключи.
- Реальный скриншот приложения: без личных данных; до получения в README стоит помеченная заглушка.
- Лицензия, NOTICE и кредиты (Parakey, Richard Courtman; SuperDictate, shlgd) сохраняются. Переименование не отменяет
  авторства.
- Название `Lexomorph` на занятость (домены, товарные знаки, GitHub, brew, PyPI) не проверялось; спецификация правовой
  чистоты не подтверждает.
- Фраза «formerly SuperDictate Next» используется один-два релиза или до публикации миграционных заметок.
