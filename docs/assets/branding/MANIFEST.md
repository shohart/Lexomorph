# Lexomorph brand assets: manifest

Imported unchanged from the owner's brand bundle (`Lexomorph_Brand_Assets/`, 58 files).
Every file was compared with the bundle's own `MANIFEST.json` after copying: 58 of 58 SHA-256 values match.

## What these files are

- The icons and `source-originals/` are **raster, generated imagery** with no vector master. The six feature cards, the
  README hero and the social previews were **redrawn as editable SVG masters** (`svg/`, status "SVG master") with
  audited wording; their PNG/WebP files are exports of those SVGs. The earlier concept rasters moved to
  `source-originals/features-concept-v1/` and `source-originals/readme-social-concept-v1/` (history kept).
- The paths `assets/svg/` and `assets/png/` that `ASSET_GUIDE.md` and `IMPLEMENTATION_TASK_EN.md` describe do not
  exist in the bundle. Feature cards are now 1200 x 675 px (SVG masters); the bundle's own cards were about 460 x 345 px.
- These are brand concept images. They are **not screenshots** of the application and must not be presented as such.
- The icons are not wired into the macOS or Windows builds on this stream (documentation only).
- Fonts are not included, and none should be added without a licence check.

## SVG masters and rendering

- `svg/<card>.svg` and `svg/<card>.ru.svg` (English for README, Russian for README.ru): 1200 x 675. `svg/readme-hero-1280x640.svg`,
  `svg/lexomorph-social-1200x630.svg`, `svg/lexomorph-social-1280x640.svg` (no Russian variants).
- Text is `<text>` with `font-family: Inter, 'Segoe UI', system-ui, sans-serif`; no embedded fonts, no filters, no external references.
  Glow is done with gradients and translucent strokes, so GitHub renders the SVG the same way.
- PNG/WebP exports were rendered with headless Google Chrome (1x scale) from a temporary copy with the font replaced by
  Liberation Sans, because Inter is not installed on the build host. Layout was also checked with DejaVu Sans (the widest fallback): no clipping.
  If Inter is installed, re-render for the exact look. Fonts were not added to the repository.
- Palette: `#0B1020` background, `#11182B` surface, `#5DA9FF` / `#5EE7D8` / `#8C7CFF` accents, `#F3F6FC` / `#AAB6D3` text.

## Card captions (exact text in the SVGs)

| Card | Text (EN) |
|---|---|
| adaptive-dictation | Speech-to-text tuned to your vocabulary and domain, with hints and rules you control. |
| personal-vocabulary | Your terms, names and replacements, applied on every dictation. |
| correction-learning | Accepted corrections become reviewable rules. Undo or disable any time. |
| style-modes | Polish, structure or formalize, or create your own rewrite modes. |
| cross-device-sync | Optionally sync your vocabulary, ASR terms, rewrite modes and usage stats between macOS and Windows. |
| local-first-privacy | Runs on local models. No account needed; sync and external LLM endpoints are opt-in. |

Notes: model downloads and, on Windows, update checks still use the network by default, so the privacy card does not claim "offline"
or "network off by default". Mode and statistics sync is unreleased on the audited stream (README Sync table); the sync card follows the
owner's statement that the feature exists. Settings, hotkeys and the active mode are not synced and are not claimed.
